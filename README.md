## Descrição

Repositório da atividade avaliativa de versionamento e lógica de programação em Python. Contém a resolução de 25 exercícios organizados em cinco partes — variáveis e entrada/saída, condicionais, `while`, `for` e listas —, cada um em um arquivo próprio e versionado ao longo do desenvolvimento.

## Tecnologia utilizada

- **Linguagem:** Python 3.14.6
- **Versionamento:** Git 2.55.0
- **GitHub CLI:** v2.101.0

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/<seu-usuario>/exercicios-python.git
   cd exercicios-python
   ```
2. Certifique-se de ter o Python 3 instalado (`python --version`).
3. Execute qualquer exercício individualmente, indicando o caminho da pasta da parte correspondente:
   ```bash
   python exercicios-parte1/exercicio_01.py
   ```
4. Os exercícios que pedem dados ao usuário exibirão um `input()` no terminal — basta digitar o valor solicitado e pressionar Enter.
